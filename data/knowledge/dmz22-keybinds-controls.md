# DMZ v2.2 default keybinds and controls

Rebind in Options > Controls, category DragonMine Z (rhythm lanes under DragonMine Z Minigames). Left Alt is the Second Function modifier.
- V: Character menu (before character creation it opens creation). Party, Skills, Quests, Minigames and Config tab keys exist but are unbound.
- X (hold): Utility menu wheel (forms, stack forms, movement, racial, fusion).
- C (hold): charge Ki and raise Power Release. Double-tap C: jump to max release (1% max Ki per 5% release). Keep holding at full Ki: Ki Surge. Alt+C: lower release.
- G (hold): use the action selected in the Utility menu. Double-tap G: instant transform. Alt+G: drop one form, or the racial secondary action.
- Alt + right-click: basic ki blast. Right-click with empty hands: block (parry if timed).
- Ctrl+Alt + right-click (hold) on a player: Ki Transfer.
- R: dash. Z: lock on.
- F: toggle flight. Alt+F: switch Combat Fly / Search Fly.
- F4: Ki Sense (Combat mode, Search mode, off); with a scouter it toggles the scouter readout.
- H tap: Instant Transmission to your locked target. H hold: IT destination menu (IT level 5+). In a Space Pod, H opens the pod menu.
- Alt+1-4 and Ctrl+1-4: technique slots 1-8.
- Instant Transform: unbound.
- Minigames: rhythm A S K L (or arrow keys), Shadow Boxing types letters, Esc pauses.
