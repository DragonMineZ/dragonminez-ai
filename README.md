# BulmaAI — DragonMineZ Discord Bot

BulmaAI is the official Discord bot for the [DragonMineZ](https://github.com/DragonMineZ/dragonminez) Minecraft mod community. It provides AI-powered support, bug reporting, crash log analysis, Patreon beta access, and automated update announcements — all from Discord.

## What it does

- **AI Support** — Ask questions in a support thread and BulmaAI answers using our [wiki](https://wiki.dragonminez.com) and FAQ knowledge, including reading attached logs and screenshots.
- **Bug Reports** — Report a bug and BulmaAI helps triage it, linking it to a tracked GitHub issue when needed.
- **Crash/Log Help** — Post or upload a `latest.log`, `debug.log`, or `crash-report.txt` and BulmaAI automatically summarizes the errors for you.
- **Patreon Beta Access** — Link your Patreon account and request/gift beta whitelist access for the mod.
- **Announcements** — New mod builds, patch notes, and CurseForge releases are posted automatically, with translations for other supported languages.
- **Moderation** — Automatic protection against spam, raids and malicious/phishing links, plus a full staff moderation toolkit. Banned members can appeal right from the ban message.

## Commands

| Command | Description |
|---|---|
| `/about` | Get information about the bot. |
| `/loghelp` | Get help finding your latest.log or crash-report.txt file. |
| `/patreon beta-access` | Request DragonMineZ Patreon beta access. |
| `/patreon link` | Link your Patreon account. |
| `/patreon gift` | Give your beta access slot to another member. |
| `/patreon edit-gift` | Move a gift to someone else or change its Minecraft username. |
| *Report message* | Right-click a message → Apps → **Report message** to flag it to the staff team. |

Support tickets, bug reports, and log parsing don't need a command — just post in the relevant channel/thread or attach your log file, and BulmaAI responds automatically.

*Some additional commands are staff-only (moderation, tickets, GitHub issue management); server settings, presets and announcements are managed from the web panel and aren't listed here.*

## Getting Help

Open a support ticket and ask BulmaAI directly.
